# Caption

Заголовок раздела с содержимым под ним.

::: info Основа компонента
Компонент построен на [Typography Title](https://antdv.com/components/typography) из Ant Design Vue.
:::

<div class="demo">
  <Caption label="Настройки профиля">
    <p>Здесь может располагаться содержимое раздела.</p>
  </Caption>
</div>

```vue
<Caption label="Настройки профиля">
  <p>Здесь может располагаться содержимое раздела.</p>
</Caption>
```

## Уровень заголовка

По умолчанию используется `level="4"`. Доступны уровни от `1` до `5`.

```vue
<Caption label="Основной раздел" :level="2" />
```

## Props и слоты

| Prop | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `label` | `string` | обязательный | Текст заголовка |
| `level` | `1 \| 2 \| 3 \| 4 \| 5` | `4` | Уровень Typography Title |

Default-слот отображается сразу после заголовка.
